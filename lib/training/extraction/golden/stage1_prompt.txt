Classify every sentence as extract or skip. Group adjacent related sentences into concept spans. Full coverage required: every sentence must appear in exactly one span.

Extract: decisions, designs, constraints, tradeoffs, preferences, resolved knowledge.
Skip reasons: ephemeral (pleasantries, filler), trivial (obvious/low-value), generic (reference facts anyone could look up), already_known (restates working memory entry), unresolved (open question without answer).

Rules:
1. Every sentence ID must appear in exactly one span. No gaps, no overlaps.
2. Adjacent sentences about the same concept may share a span.
3. Non-adjacent sentences must NOT share a span.
4. Skip unresolved questions — only extract decided/resolved knowledge.
5. Skip generic reference facts (API docs, standard procedures, how-tos).
6. Check working memory — skip if the candidate restates an existing entry.
