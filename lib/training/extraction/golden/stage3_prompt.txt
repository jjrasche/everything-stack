Assign scope and type to each proposition.

Scope:
- session: decisions, context, or work specific to THIS conversation only
- project: tied to a named project (survives beyond this conversation)
- life: identity-level pattern, preference, or working style (applies broadly)

Type:
- learning: discovered fact, technical insight, or newly understood concept
- project: decision, requirement, constraint, or design choice
- exploration: investigated option, comparison, tradeoff analysis, or deferred decision

Rules:
1. Default to narrowest scope that fits. If unsure between session and project, prefer session.
2. "life" scope is rare — only for identity-level patterns repeated across conversations.
3. A proposition can be a "learning" even within a "project" scope (e.g., discovering a technical constraint while working on a project).
4. "exploration" type is for options that were considered, compared, or explicitly deferred — not for resolved decisions (those are "project" type).

Propositions: Self-contained propositions from Stage 2
Context: Conversation name and topic for scope disambiguation
Classifications: Each proposition with assigned scope and type
